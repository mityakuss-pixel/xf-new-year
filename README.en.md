# [nt] New Year decorations

New Year decorations for XenForo 2.3: snowfall, snow on blocks, a hat on the logo and a countdown to the New Year.

## Features

- **Snowfall.** Three layers of flakes with different sizes and speeds. Snow is paused in background tabs and turned off when "reduce motion" is enabled in the OS.
- **Snow caps** on category blocks, sidebar blocks and buttons like "Post thread". Every block gets its own cap, and they change once a day.
- **A hat on the logo**, if the logo is an image.
- **A New Year countdown** in the navigation that turns into a greeting in January.
- **Opt-out per user** with a checkbox in account preferences.

## Requirements

XenForo 2.3.0 or later.

## Installation

1. Download `NT-NewYear-1.0.4.zip` from the [releases page](https://github.com/mityakuss-pixel/nt-new-year/releases/latest).
2. In the admin control panel open **Add-ons → Install/upgrade from archive** and choose the archive.

A Russian translation is available as `language-Russian-(RU)-NT-NewYear.zip`. Unpack it and import the file via **Appearance → Languages → Import language** over your Russian language.

## Configuration

- **Setup → Options → [nt] New Year decorations**: when to show the decorations (15 December to 14 January by default, or "always" and "never"), the number of flakes, snow caps, the hat and the countdown.
- **Appearance → Style properties → [nt] New Year decorations**: snow and cap colors, the countdown look, the hat size and position.
